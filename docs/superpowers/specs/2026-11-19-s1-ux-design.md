Alternative of renderer-only validation would risk contradictory previews; shared core per-tile site checks keep one authority. Alternative of replacing road commands/release-commit is unnecessary: retain explicit atomic confirmation and change only draft ordering. Preserve ordinary catalog construction drag-anywhere behavior. Valid release commits once free; invalid release retains selected origin and move mode, authoritative original remains unchanged. Tap remains a deliberate repositioning option. Circular X Cancel centered at bottom with >=44-point target, explicit accessibility identity; cancels only preview.
