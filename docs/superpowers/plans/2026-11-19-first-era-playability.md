# First-era playability implementation plan

Goal: an ordinary player can start, understand the next useful action and complete the Stone Age without developer resources. Dima's direct priority supersedes visual/roads/NPC work for this iteration. Preserve all economy values, geography, savev5, historical rewards/readiness, compact menus and gestures. Execute inline with TDD and one final independent review; commit each coherent step.

Design decision: retain seven existing chapters and thresholds. A non-persistent, read-only guidance resolver selects the next incomplete objective and explains necessary research, resource production/modes, construction, staffing, housing or exploration first. Knowledge production must be explained even though the circle belongs to a later chapter. Keep next action visible when goals are collapsed; expansion shows why/how and opens existing Buildings/Research/inspection/resource/population/Explore screens. Actions navigate only; player still confirms real transactions and placement. Show clear era completion with continued sandbox play; no new age.

Alternatives considered: reorder chapter requirements (unnecessary progression change); static tutorial text (cannot diagnose missing production/prerequisites); forced tutorial/auto-buy (reduces freedom). Choose contextual optional guidance, bounded recursion and current catalog/rules, no save fields. Exact recommendation order is an implementation choice; no optimality/enjoyment claim.
