# Isolated gameplay review controls

Direct owner request after GAME-LOOP-01; owner explicitly selected a separate review copy preserving normal progress. [Bounded plan](../../plans/2026-11-20-isolated-gameplay-review.md). No normal economy, signing, art, physical installation or gameplay backlog changes.

In a Debug build, open **Developer tools → Review this game**. This copies the selected healthy normal game at its current state into its own review companion. Open Developer tools again to use existing **1×/2×/5×/10×**, pause, time advance, fast construction, and **Add250of each resource** within existing capacities. The HUD clearly says **REVIEW COPY**. Return to normal leaves accelerated progress and grants in the copy. After relaunch, the normal game opens ordinarily; **Resume review copy** restores the separate review progress with default speed/settings and no review offline catch-up.

The existing authored developer companion remains independent. Review mode hides scenario selection/reset and guards those commands. Starting/resuming review is blocked during pending scenario work, preventing a suspended authored-scenario task from overwriting review data. A damaged source game's protected fallback cannot become a review copy. First review creation is written before publishing mode; a failed final save keeps the current copy open and visible instead of discarding unsaved progress. Existing review data is resumed, never silently reset.

The source normal game retains ordinary wall-clock/offline behavior when resumed. It never receives review time multipliers or grants. New entry points/UI remain DEBUG-only; all seven Release API exclusion probes cover existing and new controls. The permanent SaveInspector and app share review-marker validation, including review backups; missing/false markers and damaged review files fail without changing source bytes. Review envelopes omit an unused duplicate original-state snapshot; authored developer comparison snapshots are unchanged.
