# UI2-1 Riverbend founding review

Open **Developer tools → Open separate Lodge and paths review** in Debug. It opens a new, separate review save; normal progress, developer/review companions and the delivered Economy Lab stay independent. The view starts paused. Resume 1× time or use the explicitly labeled 60-second review step; reopening grants no offline time.

1. Upgrade Campfire to Founder’s Lodge for **12 Wood + 4 Stone**, without research or a road. Civic ID 0 and the logical 1×1 footprint remain fixed. There is no +10 Wood award, no storytelling completion, no discovery credit, and no cultural/worker change from the upgrade.
2. The Lodge door faces the free starter footpath. Both highlighted hut origins are legal, visible fallback choices at the default camera. Tap the Lodge to inspect it, then tap either plot or choose the recommendation. Tap/drag the hut outline to select a site. The complete 2×2 hut must remain outside the civic yard and have a supported clear opening route before payment. This bounds this one-hut review; ordinary terrain validation remains unchanged. Across-river terrain is never converted into buildable paths.
3. Build the hut for its unchanged **20 Wood**, with **15 seconds** of paid construction. A disconnected construction still completes. Inactive housing explains the missing path; reserves and paid work remain yours.
4. Use **Draw path** and tap the starter/route tiles to sample a cardinal stroke, or **Preview suggested free route**. Confirm commits the preview using the existing road API. Any full civic footprint edge remains a valid source; the pictured door is a teaching cue, not a directional graph rule. Connecting the hut activates its existing housing service.
5. Disconnect and reopen. Stocks, the finished hut, civic identity, level history and completed objectives remain. Reconnect for service. If a second window changes this separate save, stale commands are rejected; close/reopen to refresh.

The captured deterministic route starts with 100 Wood / 50 Stone / 60 Food. Founding gives **88 / 46 / 60**; paying the hut gives **68 / 46 / 60**. An explicit 60-second step leaves **68 / 46 / 59**: existing campfire Food 2/min minus population consumption 3/min. Paths cost zero. Disconnect/reload changes none of these stocks. The scoped persisted civic history is `[1,2]`, objective `1:civic-level-2`; completed hut later adds `1:building-hut` and chapter 1. The visible current objective follows present service, so it can ask to reconnect while completed construction history remains earned.

The procedural stone-and-timber shelter and map annotations are Debug review drawings; no runtime art file is replaced. Human comprehension, enjoyment, accessibility acceptance, physical-device performance and production appearance approval are not established by these simulator checks. UI2-2 is a separate goal and is not begun here.
