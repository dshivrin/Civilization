## Review limits

Provisional procedural cliff/wall/gate/character appearance; no new raster art. The first hut is unique and inside the reserved enclosure; later expansion uses the ordinary catalogue and currently available terrain/rules. The enclosure is a fixed review layout, not a player-drawn defense system, tower/combat feature or new progression unlock. Price is a clearly labeled review assumption, not adopted economy balance. Forest comparison deliberately uses the original temporary forest profile, not a saved Foothill exploration migration. Ambient figures retain the inherited conservative planner; routes crossing a new barrier are removed/rebuilt rather than rerouted, and hills remain excluded for these cosmetic villagers. Only the amber proof uses the full-map slope-aware collision graph. Simulator evidence establishes tested software behavior, not human acceptance, physical-device performance or maximum text-size support.
