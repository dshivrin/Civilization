## MC-002 — S1-Geography design gate (20 Nov 2026)

**Authority/status:** Dima authorized autonomous S1-UX → S1-Saves → S1-Geography → environment graphics, with consequential decisions escalated. S1-Saves implemented, awaiting human acceptance; signed installation succeeded but physical first launch/index initialization is **not verified** (locked iPhone). Do not reset/uninstall. **Approved requirements (canonical roadmap):** MAP-001 larger persistent geography preserving existing world/IDs/investments; MAP-002 stone quarry reachable on settlement side of river without bridge; MAP-003 cloud-hidden unexplored terrain with readable edges, reduced-motion/performance fallback, no hidden construction; MAP-004 expedition cost/time/persistent discovery with no duplicate charges or early reveals. GEO-001–008 regional civilizations/assets/shared knowledge/trade and MAP-005 across-era expansion remain approved **future/deferred**, not S1-Geography deliverables.

**Proposed bounded design, not human-approved:**
1. Preserve existing 32×24 river-clearing-v1 coordinates, terrain, resource IDs, placed buildings, roads, exploration state, construction/research/rewards, and legacy save v5. New map cells are additive and deterministic; do not recenter/scale/reseed legacy terrain. Explicit map-definition/version migration; transactional staging/validation/commit, reversible failure without overwriting the original. Prefer per-world stable geometry/version over global catalog-size assumptions.
2. Candidate expanded size **48×36 tiles** for evaluation, not authorization. Expand toward positive grid axes to preserve existing tile coordinates; benchmark against 32×24 and alternate dimensions before approval. The exact seam, coastline/river continuity, expansion for existing worlds versus only newly created worlds, and whether the original playable 32×24 remains as-is are open human decisions.
3. Quarry must be on the settlement side of the river, visible/discoverable through legitimate first-era actions and reachable without a bridge; preserve all existing deposits and IDs. Proposed deterministic placement in added near-side land only if map geometry validates it; no quarry overwrite or free resource grant. Existing-world quarry remediation policy needs human approval.
4. Clouds/fog render over undiscovered tiles, conceal resources/landmarks, prevent interaction/construction/road placement, and never replace persistent discovery state. Use efficient overlays and reduced-motion/static fallback; no renderer replacement. Previously discovered tiles remain discovered.
5. Expeditions retain existing cost/time and earned discoveries; adapt destination validation to expanded bounds, commit cost and reveal exactly once, preserve pending expeditions across save/switch/relaunch/offline, and never leak hidden tiles via previews or map edges. New expedition range/duration scaling is a human-facing product decision if existing progression would materially change.

**Required human decisions before affected map code:** (A) exact target dimensions and hardware budget; (B) whether existing settlements expand in-place, remain 32×24, or use an opt-in non-destructive expansion; (C) exact coordinate/seam policy for the legacy map; (D) existing-world quarry placement/remediation if its current near-side stone access is insufficient; (E) expedition scaling for added area (reuse current mechanics versus new costs/times). Suggested defaults: 48×36 candidate, additive stable coordinates, non-destructive in-place expansion only after explicit backup/migration proof, quarry added without changing existing deposits, reuse existing expedition economics initially. These are **proposals**, not authorization.

**Acceptance gate:** compare before/after full normal and developer saves; original 32×24 cells and IDs exact; five buildings and 15 roads in latest normal preservation case retained; discovery/expedition idempotence, corrupt/partial migration recovery, save-switch isolation, no grants/rewards/reset; full Debug/Release plus Release exclusion probes and native phone/mini/Pro UI, measured camera/cloud performance, safe signed-device backup and actual launch only when unlocked. Report physical observations separately. Human gameplay/visual/touch acceptance remains open.

**Exclusions:** second era, new regions/civilizations, trade, warfare, backend, monetization, procedural replacement of existing world, altered original geography or rewards, forced reset, renderer/signing changes, large art batch, new functional roads, other deferred systems. Environment graphics follows Geography with separate provenance/assets and human art review.
